# DecodeLabs AI Internship Tasks

**Author:** Saniya Inam
**Internship:** DecodeLabs — AI Track (Batch 2026)
**Track:** Artificial Intelligence Engineer, Industrial Training Kit

This repository contains my completed project submissions for the DecodeLabs AI Internship. Each project builds on the last — starting with rule-based logic and moving into supervised machine learning.

## Projects

### [Project 1: Rule-Based AI Chatbot](./project-1-chatbot)
A simple rule-based chatbot built in Python that responds to predefined user inputs using dictionary-based lookup, input sanitization, and a continuous input loop. Demonstrates control flow, decision-making logic, and basic AI concepts — the foundation before moving into machine learning.

**Key skills:** control flow, decision-making logic, data structures (dictionaries)

### [Project 2: Data Classification Using AI](./project-2-classification)
A supervised learning classification model trained on the Iris dataset using K-Nearest Neighbors (KNN). Covers the full ML pipeline: feature scaling, train/test splitting, model training, hyperparameter tuning (choosing K), and evaluation using accuracy, confusion matrix, and F1 score — plus bonus algorithm comparison and testing on unseen data.

**Key skills:** data handling, supervised learning, model training, evaluation
